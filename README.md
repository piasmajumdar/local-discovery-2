# 🌍 Local Discovery — AI-Powered Geospatial Recommendation Platform

## 📌 Overview

Local Discovery is an AI-powered geospatial recommendation platform designed to help users discover trustworthy nearby businesses more intelligently. The platform combines interactive maps, recommendation systems, sentiment analysis, and geospatial computing to improve local business discovery in tier-2 and tier-3 regions.

Users can search nearby restaurants, pharmacies, grocery shops, cafes, and services while merchants can self-list their businesses with detailed product and service information.

---

## 🚀 Features

### 🗺️ Geospatial Business Discovery

* Real-time nearby business search
* Interactive map-based exploration
* Distance-aware recommendations
* GPS-based location support
* GeoJSON-based shop storage

### 🤖 AI-Powered Recommendation System

* Trust score generation from customer reviews
* Fine-tuned BERT sentiment analysis model
* Hybrid recommendation engine:

  * Collaborative Filtering
  * Content-Based Filtering
  * Geospatial Filtering

### 🏪 Merchant Self Listing

* Add and manage businesses
* Upload product/service catalogues
* Business tags & categories
* Opening/closing hours
* Image upload support
* Live map pinning

### 🔐 Authentication & Security

* JWT authentication
* OTP email verification
* Password hashing with bcryptjs

### 📱 Responsive User Interface

* Mobile-first responsive design
* Dynamic filtering and search
* Interactive UI components
* Smooth navigation experience

---

# 🧠 AI & NLP Integration

The platform integrates a fine-tuned **BERT sentiment analysis model** trained on 13k+ balanced Yelp reviews to classify customer reviews and generate implicit trust scores.

### Model Highlights

* BERT-base-uncased
* Sentiment Classification
* Review-based Trust Estimation
* Cold-start problem mitigation
* Hybrid recommendation support

# 🧩 System Architecture

## User Flow

1. User searches nearby businesses
2. Backend performs geospatial query
3. Recommendation engine calculates ranking
4. BERT model evaluates review sentiment
5. Trust score generated dynamically
6. Results displayed on interactive map + cards
